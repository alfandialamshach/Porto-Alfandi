# Personal Portfolio Website — Alfandi Alamshach

Welcome to my personal portfolio repository! This website showcases my projects, technical skills, work experience, and background as an **Information Technology Graduate** passionate about **Full-Stack Development, Networking, and Cybersecurity**.

Built with a modern **Glassmorphic Dark Mode UI** featuring Manchester City sky blue accents, smooth micro-interactions, and high performance.

---

## Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Library**: [React 18](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer-motion.com/)
- **Analytics & Insights**: `@vercel/analytics` & `@vercel/speed-insights`

---

## Key Features

- **Glassmorphic Dark Mode**: Deep Midnight background (`#090d16`) with ambient sky blue glow effects and glassmorphism components.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.
- **Featured Projects**: Highlights key projects (Dompet Warga, HRIS, Smart Village Klapagading, Mini Clinic Information System).
- **Specialized Skills Grid**: Visual cards highlighting core competencies in React Native, React, Next.js, TypeScript, Node.js, Express.js, MySQL, Linux, & Cisco.
- **Work Experience Timeline**: Career milestones and internships formatted with an interactive timeline.
- **Interactive Contact Card**: Direct email CTA and social connection links.

## Local Development

Follow these steps to run the project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/alfandialamshach/Porto-Alfandi.git
   cd Porto-Alfandi
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser to view the site.

4. **Build for production:**
   ```bash
   npm run build
   ```

## Project Structure

```text

```
